# **Project Complexite**

Ce dépôt contient des implémentations et des exemples de divers algorithmes et structures de données simples et complexes, notamment les tas, les arbres binaires de recherche, les arbres B et les listes doublement chaînées, ainsi que le problème NP-complet de partition.

Ce projet contient deux parties :
1. La première partie concerne les structures de données et leur implémentation.
2. La deuxième partie concerne le problème de partitionnement.
